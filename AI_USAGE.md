# Use of AI (SI) tools in Field Shift

This file is our disclosure of software intelligence (SI) / AI use, as required by the NASA Space Apps 2026 rules for code and data. The same statement appears in the [README](README.md), in the `ai_disclosure` field of [`data/sources.json`](data/sources.json), in the API description at `/docs`, and as a header comment in every Python file.

## Tools used

| Tool | Provider | What we used it for |
|---|---|---|
| Claude, via Claude Code | Anthropic | Code generation and refactoring: project skeleton, NASA POWER client and cache, climate summary and the FAO-56 Penman-Monteith ET0 implementation, FastAPI backend and schemas, sample/mock data, tests, helper scripts, and documentation drafts. |
| Claude chat | Anthropic | Research support and planning: finding candidate datasets and methods, outlining the architecture, and drafting the task breakdown. |

## What the human team did

- **Problem framing:** chose the problem (crop rotation decisions for farmers, with the Nile Delta as the demo case) and what the tool should and should not do.
- **Data sources and methods:** chose NASA POWER, MODIS NDVI, ISRIC SoilGrids, FAO ECOCROP and FAO-56, and the methods built on them (Penman-Monteith ET0, crop coefficients, weighted scoring).
- **Agronomic rules and their sources:** define the rotation rules (e.g. legume after cereal, no same family back-to-back, cycle must fit the season) and fill crop parameters from published references, recorded in `data/sources.json`.
- **Review and testing:** review and test all AI-generated code before it is merged.
- **Verification:** check results against published references (e.g. the FAO-56 worked examples) and against independent data where available.

## Where AI was used, by folder

- **AI-generated:** written by AI from the team's specifications, then reviewed by the team.
- **AI-assisted:** written by the team with AI help, or AI-written and substantially edited by the team.
- **Human-written:** written by the team without AI.
